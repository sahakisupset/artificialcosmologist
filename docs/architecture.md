# Architecture

## Agents

### LiteratureAgent
Retrieves papers from ADS and arXiv.

### TheoryAgent
Generates competing explanations from evidence.

### AssumptionAuditor
Detects implicit assumptions.

### CriticAgent
Attempts falsification.

### SymbolicEngine
Derives mathematical consequences.

### ScoringEngine
Compares predictions against observations.

### EvolutionEngine
Maintains a population of competing theories.

## Workflow
Retrieve Papers
 -> Build Knowledge Base
 -> Generate Theories
 -> Audit Assumptions
 -> Critique Theories
 -> Derive Equations
 -> Predict Observables
 -> Compare To Data
 -> Rank Theories
 -> Evolve Next Generation
